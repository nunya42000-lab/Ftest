Machine tone capture

Records the tones your machine plays, so Follow Me can recognise them without every user calibrating first.

  1. Put the phone where it normally sits while you play.
  2. Turn on the microphone, then start recording.
  3. Let the machine play several rounds — the longer the better.
  4. Stop, label which tone is which button, and send the result back.
